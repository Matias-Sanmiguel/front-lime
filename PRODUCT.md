# Lime

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Personas que buscan propiedades en Argentina e inmobiliarias que publican y administran avisos. Contexto confirmado por el usuario: portal tipo Argenprop.

## Product Purpose

Buscar, comparar, guardar propiedades y consultar a sus anunciantes. El panel permite gestionar publicaciones, fotos, perfil y consultas.

## Capabilities and Constraints

React y React Router, Redux Toolkit para favoritos persistidos localmente, Context para sesión. Búsqueda por URL, monedas ARS/USD y orden del lado del backend. Java ofrece la API; el modo de demostración usa datos ficticios locales.

Conservar los flujos y las contribuciones integradas de otras personas. Evitar duplicar estados, formularios y sistemas visuales.

## Brand Commitments

Nombre Lime, español rioplatense. El usuario pide una nueva identidad minimalista y linda con referencia estética Apple, incluyendo logo nuevo. La identidad editorial anterior puede reemplazarse. No copiar logotipos ni usar activos propietarios de Apple.

## Evidence on Hand

Avisos de demostración y fotografías ilustrativas en mi-app/public/data. No inventar métricas, testimonios ni garantías.
